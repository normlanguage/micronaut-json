# micronaut-json 示例归属

[English](README.md) | [简体中文](README.zh-CN.md)

本模块为类型化序列化提供 JSON 基础设施。可运行场景由 [micronaut-serde-jackson](https://github.com/normlanguage/micronaut-serde-jackson/tree/main/samples) 仓库的 `samples/` 目录负责；请通过该示例观察公开 API 的实际行为。

模块身份与固定依赖见 [module.norm](../micronaut/json/module.norm)。
