# Micronaut JSON

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable example are in `micronaut/json`. It pins Micronaut JSON Core 5.1.13 and defines its package coordinates in [module.norm](micronaut/json/module.norm). This module provides JSON infrastructure and common mapping entry points for Micronaut HTTP services.
